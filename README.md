# ServerWatch

ServerWatch is a production-style server monitoring and incident management
platform.

It monitors Linux servers and applications, collects infrastructure metrics,
detects incidents, stores monitoring data in PostgreSQL, and integrates with
Jira and Slack for incident management and notifications.

## Project Goals

- Monitor Linux servers and applications
- Collect CPU, memory, disk, uptime, and application health metrics
- Store monitoring data in PostgreSQL
- Detect and manage incidents automatically
- Integrate with Jira
- Send notifications through Slack
- Provide a web-based monitoring dashboard
- Containerize the application using Docker
- Automate CI/CD using Jenkins
- Provision cloud infrastructure using Terraform
- Deploy the platform using Kubernetes
- Implement monitoring, logging, security, and production practices

## Architecture

The project will be developed incrementally from a local monitoring agent
to a production-style cloud-native deployment.
